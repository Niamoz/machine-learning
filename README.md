# machine-learning

This project includes four different machine learning applications developed in Google Colab.

## Project Overview

The notebook contains the following analyses:

### 1. House Price Regression
Several regression models were compared:

- Linear Regression
- Ridge Regression
- Principal Component Regression (PCR)
- Partial Least Squares Regression (PLS)
- Multi-Layer Perceptron (MLP)

Best R² score: **0.9405** with MLP Regression.

### 2. Customer Segmentation
K-Means clustering was applied using annual income and spending score.

- Number of clusters: 5
- Silhouette score: **0.7151**

### 3. IMDB Sentiment Analysis
A Simple RNN model was used for binary sentiment classification of movie reviews.

- Test accuracy: **84.81%**

### 4. Fashion-MNIST Image Classification
A Convolutional Neural Network (CNN) was used for image classification.

- Test accuracy: **90.45%**
